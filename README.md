## 📌 Overview
This repository is a collection of **50+ Machine Learning mini projects** covering multiple domains such as:

- 📊 Regression  
- 🔍 Classification  
- 🧠 Natural Language Processing (NLP)  
- 👁️ Computer Vision  
- 📈 Time Series Forecasting  
- 🤖 Recommendation Systems  

This repo represents a **hands-on ML journey**, focusing on real-world datasets and practical implementation.
