# 🚢 Titanic Survival Prediction

## 📌 Project Overview

This project focuses on predicting passenger survival on the Titanic using Machine Learning techniques. By analyzing passenger data such as age, gender, class, and other attributes, the model learns patterns that influence survival outcomes.

The project follows a complete data science workflow including data preprocessing, exploratory data analysis (EDA), feature engineering, model building, and evaluation.

---

## 🎯 Objective

* Predict whether a passenger survived or not.
* Apply classification algorithms to real-world data.
* Perform data cleaning and feature engineering.
* Evaluate model performance using standard metrics.

---

## 📂 Dataset Information

The dataset used in this project is the famous **Titanic dataset**, commonly used for beginner ML projects.

### Files Used:

* `train.csv` → Training dataset with survival labels
* `test.csv` → Test dataset without labels
* `resultfile.csv` → Output predictions generated by the model

### Dataset Source:

* Kaggle Titanic Competition
  [https://www.kaggle.com/competitions/titanic](https://www.kaggle.com/competitions/titanic)

## 🔍 Project Workflow

### 1. Data Loading

* Import datasets using pandas
* Inspect structure and missing values

### 2. Data Preprocessing

* Handle missing values
* Convert categorical variables into numerical form
* Feature selection and cleaning

### 3. Exploratory Data Analysis (EDA)

* Visualize relationships between features and survival
* Analyze distributions and patterns

### 4. Feature Engineering

* Transform relevant features
* Encode categorical variables

### 5. Model Building

* Train a classification model using:

  * Random Forest Classifier

### 6. Model Evaluation

* Accuracy score used for evaluation
* Compare predictions with actual outcomes

### 7. Prediction

* Generate predictions on test dataset
* Export results to `resultfile.csv`
